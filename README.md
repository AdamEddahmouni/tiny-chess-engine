A 4 KB Python chess engine: iterative-deepening alpha-beta search with
quiescence, transposition table, killer moves and piece-square evaluation. It
drives the contest env directly through its HTTP API and uses a fixed node
budget per move, so play is deterministic and replays byte for byte.

## Run it

```sh
python3 main.py
```
